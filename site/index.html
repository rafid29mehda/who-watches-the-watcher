Who watches the watcher?

Rafid Mehda, Independent Researcher

Companies are starting to put a second model in front of an AI agent's actions, to stop it when it has been tricked by text hidden in an email or a web page. That monitor has to read something to judge an action. If it reads the agent's whole transcript, it also reads the attacker's text. We measured what a monitor should be allowed to see.

The question

An agent receives a task from its user, calls tools, and reads what comes back. An attacker who controls some of that content, such as one email in the inbox, can plant instructions that steer the agent into sending money or data somewhere it should not. A monitor reviews each consequential call before it runs and can halt the agent.

We gave the same monitor model five different views of each proposed action and asked which view catches attacks while letting legitimate work through.
